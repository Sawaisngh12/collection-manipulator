# Student Data Organizer

## 📌 Project Description
The Student Data Organizer is a Python-based project that helps users manage student information. It uses lists, dictionaries, tuples, and sets to store and organize student data.

## 🚀 Features
- **Add Student:** Add student ID, name, age, grade, date of birth, and subjects.
- **Display All Students:** View all stored student records.
- **Update Student:** Update a student's age and grade using their ID.
- **Delete Student:** Remove a student record using their ID.
- **Display Subjects:** Show all unique subjects offered by students.
- **Exit:** Exit the program.

## 🛠️ Technologies Used
- Python 3
- Lists
- Dictionaries
- Tuples
- Sets
- Loops and Conditional Statements
- User Input and Output

## ▶️ How to Run
1. Install Python 3.
2. Save the code in a file named `student_organizer.py`.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python student_organizer.py
```

## 📚 Concepts Learned
- Managing data using lists and dictionaries.
- Storing multiple values using tuples.
- Using sets to store unique subjects.
- Using loops and conditional statements.
- Performing CRUD operations (Create, Read, Update, Delete).
